Understanding UNC

UNC means Universal Network Compatibility. It tests how well an executor supports a range of scripting APIs and functions. A higher UNC result generally suggests broader API compatibility—but it is not a complete measure of an executor.

UNC does not directly measure FPS or execution speed, and a high score does not guarantee an executor is safe. Compatibility and performance are different things.
