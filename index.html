EXECUTOR INFORMATION

Understanding UNC

UNC

UNC stands for Universal Network Compatibility. It is a set of tests used to check how well an executor supports a range of commonly used scripting APIs and functions.

API compatibility
Higher UNC generally indicates broader compatibility with the APIs covered by the tests.

Not a performance score
UNC does not directly measure FPS, execution speed, or whether an executor is safe.
